## 六、按设计保留英文的类别

| 类别 | 例子 | 原因 |
|---|---|---|
| 窗口类名 | `Button` `Edit` `Static` | 同时是 Win32 类名，翻译会导致窗口创建失败 |
| `.uir` 内部类型令牌 | `ToggleButton` `CheckBox` `CtrlArray` | 文件格式标识符，翻译会破坏 `.uir` 解析 |
| 安装位置令牌 | `[Program Files]` `[Temp]` `[CVI]` | 同时是 `.cds` 文件中的标识符 |
| 配置字面值 | `True` `False` `Standard` | 会被写回配置文件或被代码比较 |
| 注册表值类型 | `REG_SZ` `REG_DWORD` | 系统定义常量 |
| 文件类型/扩展名 | `.fp` `.uir` `exe` `ico` | 技术标识 |
| 代码示例 | 警告列表中的 `int foo() {...}` | 属源码，翻译即失真 |
| 生成文件注释头 | `/* LabWindows/CVI User Interface Resource (UIR) Include File */` | 会写入用户源码，保留英文避免编码问题 |
| 内部面板名 | `Resource Tracking` `Undo Buffer` | 用户不可见 |
| 厂商/产品/总线名 | `National Instruments` `NI-DAQmx` `VISA` `GPIB` | 专有名词 |

## 七、已知限制

- 译文长度受原文字面量空间约束（`msgpatch` 会拒绝超长项），个别条目采用更简练的说法。
- 系统区域设置必须是中文(GBK/936)，否则 GBK 字节会被按西文渲染成乱码。
